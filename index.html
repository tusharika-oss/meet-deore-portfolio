Project · Bengaluru2026

Smart Battery Monitor with EKF SOC Estimation

A read-only battery monitor on an ESP32-S3 that runs beside an existing BMS, logging four LFP cell voltages, pack current and two temperatures over its own WiFi network.

Current-sensing error
8.5% vs multimetertarget ±2%
  • Implemented an Extended Kalman Filter SOC estimator with an equivalent circuit model, validated on the CALCE public battery dataset.
  • Took current sensing from 8.5% error to within ±2% against a multimeter, after diagnosing a median filter that misread pulsed current and an ADC pin shared with WiFi.
  • Found that LFP's flat mid-range voltage curve gives little signal for voltage-based correction, so the EKF relies on current integration there, which makes current calibration critical.
  • Now characterising the pack (capacity, OCV–SOC curve, internal resistance) and building an AI layer to predict and plot further battery metrics from the same inputs.
